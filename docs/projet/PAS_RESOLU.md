# Ce que nous n'avons pas résolu

Liste de départ (avenant 2, K05). L'équipe la complète. Pour chaque ligne : « pas essayé », ou « essayé, raté ». Aucune promesse de date.

- Un vrai service avec de vrais patients — pas essayé. Tout est fait avec des données inventées.
- L'hygiène — pas essayé. Aucun robot n'a été nettoyé, ni approché d'un lit.
- Le réseau d'une vraie clinique — pas essayé. Seulement notre Wi-Fi et cet ordinateur.
- La nuit — pas essayé. La carte « Nuit » existe, mais seulement pour des robots simulés.
- L'accord du personnel — pas essayé. Aucun soignant n'a été rencontré.
- Les règles sur les appareils médicaux — pas essayé. Ce prototype n'a pas été comparé à ces règles.
- La saisie d'objets par un vrai bras — pas essayé. Seulement le faux robot.
- Le lien avec le logiciel d'une clinique — pas essayé. Seulement un faux logiciel administratif, sur cet ordinateur.
