# Brique 17 — Petites tâches (samedi)

Chaque tâche : une personne, moins d'une heure, avec son test. Cocher quand le test passe.

## Samedi matin, avec le vrai défi
- [ ] Lancer le kit sur le vrai texte du défi ; relire le plan à deux ; noter dans `mots_cles.yaml` chaque mot raté, relancer.
- [ ] Mettre les heures officielles du Carnival (repas, passage devant le jury) dans `programme_48h.yaml`.
- [ ] Mettre à jour `briques/etat_des_briques.yaml` après chaque fusion (brique 15, puis les autres).
- [ ] Remplacer, dans les étapes du scénario (`connaissances.yaml`), la table, la bouteille et l'entrée par les vrais lieux et objets du défi (et les ajouter à `commun/monde.yaml`).
- [ ] Aligner le YAML du scénario sur le format de la brique 15 (chef de démonstration).

## Améliorer
- [ ] Option `--personnes N` : répartir moins de 35 personnes si l'équipe n'est pas au complet.
- [ ] Ajouter l'italien aux mots-clés (le défi peut être écrit en italien) ; un test avec un faux défi en italien.
- [ ] Phrases du scénario en suisse allemand et en chinois, relues par quelqu'un qui parle la langue, puis essayées sur le faux robot.
- [ ] Lire les tableaux Markdown de critères avec une colonne « points » séparée (un test avec un tableau).
- [ ] Repérer les chiffres de sécurité du défi (vitesse, distance, poids) et proposer la ligne de `reglages.yaml` → `securite` (sans l'écrire : feu orange).
- [ ] Sortie « page à imprimer » : le plan en deux pages A4 (résumé, chantiers, heures).
