# La fiche de vérité et le rejeu — petites tâches

Une tâche = une personne, moins d'une heure, avec son test. Cocher quand le test passe. Rien ne touche un vrai robot ; rien ne part vers GitHub sans Hiba.

- [ ] Lancer une répétition, ouvrir la page de la fiche, et vérifier chaque ligne contre la sortie de la répétition. Test : `python3 lancer.py tests briques/clinique/tests/test_fiche_complete.py` passe.
- [ ] Copier un dossier de rejeu sur une clé USB, l'ouvrir sur un autre ordinateur sans Internet, noter ce qui s'affiche. Test : ce qui s'affiche est noté dans `NON_TESTE.md`, avec l'ordinateur utilisé et la date.
- [ ] Ouvrir la page des moments après une séance et retrouver un refus du gardien. Test : `python3 lancer.py tests briques/clinique/tests/test_moments.py` passe.
